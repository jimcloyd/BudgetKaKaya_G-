# Family Budget Tracker - Frontend

React + TypeScript + Vite frontend for the Family Budget Tracker application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:3000`

## Build

To build for production:
```bash
npm run build
```

## Technologies

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- Chart.js
